# KSP VISUALS

## Project Description

KSP VISUALS is a personal photography portfolio designed to showcase different styles of photography in a simple, dark-themed website. It introduces the portfolio, displays selected photographs, provides information about the project, and includes a contact section.

## Features

* A navigation menu linking to the Home, Gallery, About, and Contact sections.
* A dark-themed design with cream text and gold accents.
* A gallery displaying six sample photographs.
* An About section describing the purpose of KSP VISUALS.
* A Contact section for contact information.
* Basic JavaScript console messages confirming that the JavaScript file is connected.

## Technologies Used

* **HTML5:** Structures the website content.
* **CSS3:** Controls the colours, typography, spacing, and gallery layout.
* **JavaScript:** Displays basic messages in the browser console.
* **Visual Studio Code:** Used to write and edit the project files.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Ensure you have an internet connection to load the sample photographs from Unsplash.

## Current Limitations

* The website does not yet include advanced interactive features.
* The photographs are loaded from external URLs rather than stored in the project folder.
* The contact section does not contain a working contact form.
